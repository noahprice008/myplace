## 1. Schedule

- Hours extend to 21:00, so slots run 9-10 through 20-21.
- **Lock / Unlock button** at the top: when locked, the grid is read-only (taps do nothing, Clear is disabled) so the week can't be changed by accident.
- **Send to spa** button removed (the preview text block stays so the week can still be read/copied manually — say the word if you want that gone too).
- Job colours updated: **Safta becomes mauve**, and a new **red = Unavailable** option is added to the palette and legend.

## 2. Em's Wall

- **Edit button** on every post: opens the composer pre-filled so text, post type, images and list items can all be changed and re-saved.
- **Time grouping**: a Week / Month / Year selector with back/forward arrows, showing only posts inside the chosen period, with the period label at the top.

## 3. Work

- **Shifts tab**: workplace filter chips ("All" plus one per workplace) so each workplace's shifts can be viewed separately, with that workplace's total for the filtered list.
- **Totals tab**: keeps combined + per-workplace figures, and adds a **History** section — pick any day (or browse by month) and see the earnings for that day, broken down per workplace and per shift.

## Technical notes

- `HOURS` in `src/routes/schedule.tsx` extends to 20; `JobId` gains `unavailable`, `--job-safta` re-tinted to mauve and a new `--job-unavailable` red token added in `src/styles.css` (light + dark).
- Lock state persists per week via the existing `usePersistentState` store.
- Post editing reuses the existing composer state in `src/routes/index.tsx` with an `editingId`; saving replaces the post in place and keeps `createdAt`, likes and comments.
- Work history derives from existing `shifts` in localStorage — no data model change.
