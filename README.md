# myplace

build and app called "Em Price". 

this app will be used on a mobile device for:

1. notes, diary, lists, and memos

unique feature is a personal news feed, simmilar to facebook, where the user can post thoughts, pictures and other media including notes and text. should be clearly labeled as "Em's Wall". user must be able to scroll up and down and view previous days posts, including the ability to comment, and like and share features

2. to record working hours and calculate earnings. 

work place 1: The Golf Spa, rate is per treatment, 100 shekels for a 50 minute session, 40 shekels for a 20 minute session. create a system that the user can, after each shift, easily mark how many of each treatment she did. 

workplace 2: The Lipmans, rate is 70 shekels an hour. create a system that the user can, after each shift, easily mark how many hours she worked, including half hours. 

create an add workplace button to create additional workplaces based on the above systems

3. be used as a personal calendar. 

show all work and other appointments on the master calendar.

4. work timetable, schedule and availibility

the user must send her availability to the spa every week. make a tool where she can select available or not available. start day sunday, time 9am to 5pm, end day saturday, time 9am to 5pm. make an export button so the user can easily send their selection

ui/ui notes: theme red, yellow and green, rastafarian theme and feel

create a fun feel and logo with simplicity and ease of use important
